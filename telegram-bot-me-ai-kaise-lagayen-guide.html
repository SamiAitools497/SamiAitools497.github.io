🤔 AI API Hoti Kya Hai?

AI API ka matlab bohat simple hai: ek aisi service jo tumhare bot ko AI se jor deti hai. Tumhara bot sawal bhejta hai, AI jawab bhejti hai — bas, kaam khatam!

"OpenAI-compatible" ka matlab samjho: agar tum ne ChatGPT wali company (OpenAI) ka naam suna hai, to bohat si sasti services unhi jaisa system use karti hain. Matlab code likhne ka tareeqa same hota hai — sirf link (base URL) aur API key badalni parti hai. Is se kaam bohat asaan ho jata hai, kyunke internet par iske hazaron free examples mil jate hain! 💡

🛠️ Step-by-Step: Apne Bot me AI Lagao

Step 1: radoxai.com Par Free Signup Karo
Website kholo, apni email se free account banao. Account bante hi dashboard khul jayega — yahan tum apni API keys aur usage dekh sakoge!
Step 2: Dashboard Se API Key Banao
Dashboard me API Keys par jao → "Create New API Key" dabao → key ka naam likho (jaise "My Bot") → Create Key dabao. Jo key mile, use foran copy kar lo — ye dobara nahi dikhegi!
⚠️ API key ko password ki tarah sambhalo! Kabhi kisi ko mat do, chat me mat bhejo, aur code me khullam khulla mat likho. 🔒
Step 3: Bot Ke Code Me /ai Command Add Karo
Agar tumhara bot Python me hai (python-telegram-bot library), to bas ek chhoti si file add karni hai jo /ai command handle kare: customer ka sawal le → Radox API ko bheje → AI ka jawab wapas customer ko de. Mere bot me ye poora code sirf ~90 lines ka hai — chhota aur simple! 🐍
Step 4: Key Ko .env File Me Lagao
Apni key ko aise .env file me rakho:
RADOX_API_KEY=apni_key_yahan_likho
.env file me key safe rehti hai aur code se alag hoti hai. Kabhi key seedha code file me mat likho!
Step 5: Bot Restart Karo Aur Test Karo
Bot ko restart karo, phir Telegram me likho:
/ai CapCut Pro me kya milta hai?
Aur dekho — AI foran jawab degi! Kaam ho gaya! 🎉
💡 Tip: AI ko apne business ke bare me batana mat bhulo! Ek system prompt me likh do ke tum kya bechte ho, prices kya hain, payment kaise hoti hai — phir AI bilkul tumhari dukaan ke salesman ki tarah baat karegi! 🏪
