Firebase config

Firebase Console → Project settings → Your apps → Web app se firebaseConfig copy karke yahan paste karo. Ye config public hoti hai (secret nahi). Referral Tracker isi se chalta hai.

Direct Publish — Seedha Website Par!

Download/Upload ke baghair changes seedha samiaitools.com par live karo! Pehle GitHub ka Personal Access Token banao:
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Generate new token → sirf SamiAitools497.github.io repo → Contents: Read and Write
3. Token copy karke neeche paste karo — ye sirf tumhare browser mein rahega, kahin upload nahi hoga!

Website Update karo
